# CiMS

Proyecto convertido a Flutter (minimal) — muestra un "Hello World".

## Cómo ejecutar ✅

1. Asegúrate de tener instalado Flutter y que `flutter` esté en el PATH.
2. En la raíz del proyecto ejecuta:

```
flutter pub get
flutter run
```

> Si quieres generar archivos de plataforma (android/ios/windows) automáticos, ejecuta `flutter create .` antes de `flutter run`.

Si quieres que ejecute `flutter create .` y `flutter pub get` por ti, dime y lo hago (necesito permiso para ejecutar comandos en tu terminal).
